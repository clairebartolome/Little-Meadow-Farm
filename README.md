
# Little Meadow Farm

## Project Overview

Little Meadow Farm is a cosy 2D pixel-art farming
simulator set in a peaceful countryside village.

The player inherits an abandoned farm and gradually
restores it through farming, exploration, crafting
and interactions with villagers.

## Technologies

- Python
- Pygame Community Edition
- PyCharm
- Git
- GitHub
- JSON
- GitHub Actions (planned)

## Planned Features

- Player movement and animations
- Farming and crop growth
- Planting, watering and harvesting
- Inventory management
- Day and night cycle
- Energy and stamina
- Shops and currency
- Farm animals
- Fishing and mining
- Crafting and cooking
- NPC dialogue
- Character relationships
- Weather and seasons
- Save and load system

## Installation

Install dependencies:

    python -m pip install -r requirements.txt

Run the game:

    python main.py

## Development Workflow

- main: Stable game releases
- develop: Development and integration
- feature/*: New features
- bugfix/*: Bug fixes

Features are reviewed and integrated through
GitHub pull requests.
