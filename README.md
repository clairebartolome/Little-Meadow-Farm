
# Little Meadow Farm

## Project Overview

Little Meadow Farm is a cosy 2D pixel-art farming
simulator set in a peaceful countryside village.

The player inherits an abandoned farm and gradually
restores it through farming, crafting, exploration
and interactions with villagers.

## Technologies

- Python 3.15.2
- Pygame Community Edition 2.5.8
- PyCharm
- Git
- GitHub

## Installation

Install the required dependencies:

    python -m pip install -r requirements.txt

Run the game:

    python main.py

## Controls

- W / Up Arrow: Move up
- S / Down Arrow: Move down
- A / Left Arrow: Move left
- D / Right Arrow: Move right
- ESC: Return to the main menu
